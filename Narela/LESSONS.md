# First lessons

## 1. Start a conversation

Practice the greeting sali, please pali, thanks dani, and goodbye vadi. Use the sentence table below to introduce yourself, ask a question, and request help.

## 2. Build a sentence

Use subject + verb + object. Add pa before the verb for past, fu for future, and du for an ongoing action. Put no after these markers to negate the predicate. Nouns add -n for plural; after a numeral that ending is optional.

## 3. Everyday sentences

| Narela | English |
|---|---|
| Sali. Nami de mi esa… | Hello. My name is… |
| Nami de ti esa ke? | What is your name? |
| Mi du lena la nara nova. | I am learning the new language. |
| Mi no kova. | I do not understand. |
| Pali hela mi. | Please help me. |
| La aku esa kana? | Where is the water? |
| Mi neda nupa an aku. | I need food and water. |
| Min pa vada a doma padi. | We went home yesterday. |
| Lin fu vena fudi. | They will come tomorrow. |
| Ti vola ta buki ka? | Do you want this book? |
| La nili seva do vila. | The child sees two birds. |
| Ta doma esa plu bala. | This house is bigger. |
| Mi pote reda. | I can read. |
| Mi ama ti. | I love you. |
| Si ti vena, mi fu fena nupa. | If you come, I will make food. |
| Mi esa hapi beko ti esa hena. | I am happy because you are here. |

## 4. Practice

Translate these before checking the answers:

1. I do not see you.
2. Do you know?
3. Two books.
4. Please come.
5. I was learning.

Answers:

1. Mi no seva ti.
2. Ti sava ka?
3. Do buki. (Do bukin is also allowed.)
4. Pali vena!
5. Mi pa du lena.

## 5. Continue learning

Read the [pronunciation guide](PRONUNCIATION.md) and [grammar](GRAMMAR.md). Practice speaking with a partner and record misunderstandings. These exercises demonstrate rules; they do not establish global ease of learning.
