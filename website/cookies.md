# Cookies policy

Effective October 17, 2026.

## What this website uses

The Language Library application does not set cookies or use tracking pixels, analytics, advertising storage, localStorage, sessionStorage, IndexedDB, or service workers. Language selection is reflected in the URL fragment. Keys, chats, translations, and preferences exist only in page memory and are cleared when you reload, leave, or close the page. No application cookie preferences need to be saved for the features currently provided.

## Browser caching is different

Your browser may cache public HTML, JavaScript, CSS, and language references to load the site faster. This is different from an application cookie and can cause old versions to appear after an update. A hard refresh or clearing the site's cache loads updated public files. The app does not intentionally cache API requests or generated audio; exported files and copied text remain under your control outside the website.

## Other services

The hosting provider and external sites have their own practices. The site does not load third-party widgets or embedded media. Optional API calls go directly to the selected provider with browser credentials omitted; the API key is explicitly included in an authentication header. Browser speech may use the browser vendor's service. Visiting GitHub or another link may allow that service to use cookies under its own policy.

## Your controls

Manage cookies, cache, saved passwords, and site permissions through your browser settings. Blocking cookies should not prevent the application library or session-only AI controls from working, although provider and browser restrictions can still affect optional services. See the [Privacy policy](https://garlicbreadwebant.github.io/Universal_Languages/#lumena/privacy) for data handling and contact information.
