## Your first sentence

`Saluton! Mi lernas Esperanton.` — Hello! I am learning Esperanto.

The dictionary gives verbs in their infinitive form. For example, `lerni` becomes `lernas` in the present tense. The object ending explains why the language name appears as `Esperanton` in this sentence.

## Contribute

Edit [lexicon.csv](lexicon.csv) and the guides. Run the language checker with --write to regenerate both dictionaries, then rebuild the website data. Corrections should follow established Esperanto usage. Edition 0.2.0 identifies this project's learning materials, not an Esperanto language version.
